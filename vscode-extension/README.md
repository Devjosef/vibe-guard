# Vibe-Guard VS Code Extension

Runs `vibe-guard scan` from command palette. Shows issues in Problems panel.

## Install
1. `npm i -g vibe-guard`
2. Install extension
3. Cmd/Ctrl+Shift+P → "Run Security Scan"

## Settings
- `vibe-guard.enabled`: true/false
- `vibe-guard.autoScan`: false (default)

## Dev
npm i && npm run compile
